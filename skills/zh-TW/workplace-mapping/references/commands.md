# 把公司的系統變成指令

在任何公司，快的做法都一樣：代理會碰的每個系統都登記成一條指令。這樣代理不用點畫面、不用每次重新想怎麼連，原本要讀一整頁的東西只讀幾行。

## 登記，不要重做

每條指令是 `workplace.toml` 裡的一筆：

```toml
[[command]]
id = "tickets.mine"
what = "我名下還沒關的工單"
run = "tools/tickets mine"     # 什麼都可以：一行 curl、一支腳本、穿進遠端桌面的通道
writes = false                 # true：只能經 wm action 執行
system = "tracker"             # 選填：它在哪個系統；這台機器不在該系統的 hosts 裡，wm run 會拒絕
max_output = 8000              # 印出這麼多字元之後，其餘存檔
readback = ""                  # 寫入類用：改動看得到時，印出結果編號
```

- `wm catalog` 是總索引；`wm run <代號> [-- 參數]` 執行讀取。已經有人做好的工具，原樣登記進來就好。
- **先做最常用的讀取。**一天要看好幾次的東西（我的工單、群裡的新訊息、建置狀態）省下的最多。同一件事手動做了第二次，就登記成指令。
- **讀取印得越少越好。**一筆一行，只留做決定需要的欄位。一條印出整頁的指令，每跑一次就付一整頁的代價。
- **預設唯讀。**會寫入、會發出去的指令標 `writes = true`，只能經 `wm action` 執行：預覽、使用者核准或常態授權、執行一次、讀回。結果不明先讀回，不重送。

## 一條指令要做到的

- 讀不到就用非零的結束碼離開。「結果是空的」和「沒讀到」必須看得出差別。
- 送出類的指令：從 stdin 收到核准過的內容，原樣送出一次，在 stdout 印出平台給的訊息編號，裡面不重試。
- 帳密在執行當下從密碼管理器或現有的登入狀態拿。機密不進 `workplace.toml`、不進參數、不進輸出、不進對話。登入被拒不重試。
- 公司稽核什麼，就在指令裡照著做：提交身分、檔案能不能離開公司環境。留一支 `status` 指令，確認這些檢查沒被關掉。
- 要有離線測試，用假的外部服務測。實機只做唯讀的冒煙測試；寫入類先在測試環境或給自己的對象驗。

## 等待

等外部結果用 `wm watch --name <什麼> --probe "<指令>" --done <正則>`：有變化才印一行，連續讀不到印 WARN，超時印 TIMEOUT，到終點印 DONE。沒輸出不等於沒事。不要臨時寫輪詢迴圈。

## 其他值得做成指令的

- 憑證索引：列出每個憑證的名稱、放在哪、有哪些欄位，不印值。
- 只有網頁登入的系統，各做一支登入指令，一步就能把登入狀態接回來。
- 常駐服務只在一台機器跑；要在另一台啟用前，先證明舊的已經停了（連不到不算停）。
