# Tidepool: daily routine

## Start of day

1. `wm brief`, then pick up from the last handoff's "Start here".
2. `wm next` for what can be done now.

## Recurring

| What | When | Where | How it is verified |
| --- | --- | --- | --- |
| Weekly meeting | Thursday 10:00 | Video call | Conclusions written to the project files the same day |
| Friday summary | Friday before 16:00 | app-team thread started by Mara | The sent message read back from the thread |

Sources: Mara, #4361, 9 March 2026.

## End of day

`wm wrapup write --start "<first thing to do tomorrow>"`. It writes the handoff into `worklog/YYYY-MM-DD.md` and checks it; report after PASS.

Open questions: whether the Friday summary is still wanted in weeks with a public holiday.
